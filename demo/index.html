🧰 六工具

📷
omr_read
图片或 PDF → MusicXML／MIDI。双引擎：smt 印刷体在役、homr 备位。产物留 run.json 引擎痕迹。
input: image/pdfoutput: musicxml/midi
🎙️
audio_transcribe
音频 → MIDI／乐谱。basic_pitch 快档秒级、muscriptor 准档约 35 倍实时。
input: wav/mp3/flacoutput: midi/musicxml
📏
theory_check
声部交叉、平行五八度、跨度三关。E／W 规则族，跨度上限可调。
input: musicxml/midi/krnoutput: 校验报告
📝
notation_check
符杠、符干、休止、谱表四关。可选 fix 模式同口径修复，改前自动备份。
input: musicxmloutput: 校验报告 + 可选修复
🔄
convert
musicxml／mxl／midi／krn 互转。transpose 给目标调则先移调，音数守恒断言。
input: 任意格式output: 目标格式
🖨️
render_score
MusicXML → verovio → 每页 SVG／PNG／PDF。A4 或贴合内容可选。
input: musicxmloutput: svg/png/pdf

🔌 如何连接真实 MCP Server

本页为前端复现演示。要连接真实 xiange-mcp server（Python 引擎），在 Claude Desktop / Claude Code 中配置：

{ "mcpServers": { "xiange-mcp": { "command": "npx", "args": ["-y", "xiange-mcp"], "env": { "XIANG_MCP_TOOLS": "（填入本机引擎工具目录）", "SMT_ROOT": "（填入本机 SMT 权重目录）" } } } }

也可以使用本目录的 npm 包：npx xiange-mcp（Node.js MCP 包装层，底层仍调 Python 工具）。
